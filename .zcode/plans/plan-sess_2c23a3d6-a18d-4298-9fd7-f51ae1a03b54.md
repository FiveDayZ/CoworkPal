# 笔记 & 备忘录一体化模块方案

## 范围（已确认）
- ✅ **统一实体 + 类型字段**：一种「记录」实体，`kind` 区分 note/memo；同一列表，筛选切换
- ✅ **内联展开编辑**：点列表项原地展开成编辑区，失焦/快捷键保存（无独立编辑页/弹窗）
- ✅ **不提醒**：备忘录只记录时间+内容，无后台提醒任务
- ✅ **基础 Markdown**：标题/列表/粗体/代码块/链接，只读渲染、编辑纯文本
- ✅ 视觉统一：复用 cwp-card / cwp-section-title / 像素滚动条 / 配色 token

## 设计原则
- **零新依赖**：Markdown 用自写极简渲染器（~80 行 TS），不引入 marked/dompurify（保持项目 react/zustand/tauri 三依赖的干净状态）
- **首屏加 textarea**：项目首个多行文本，定义 `cwp-note-editor` 类（0 圆角 + surface-800 bg + cyan focus，对齐现有 input 风格）
- **复用 FocusSessionBook 模板**：NoteBook = Vec 结构，最小改动

## 阶段 1：后端 — 数据模型 + 持久化

### 1.1 数据模型（`models.rs`，仿 FocusSession `:663-704`）
```rust
pub enum NoteKind { Note, Memo }  // note=长笔记, memo=短备忘

pub struct Note {
    pub id: String,              // "note-{timestamp_ms}"
    pub kind: NoteKind,
    pub title: String,
    pub body: String,            // markdown 源文本
    pub created_at: i64,
    pub updated_at: i64,
    pub pinned: bool,            // 置顶
    pub archived: bool,          // 归档（软删除）
    pub memo_due_at: Option<i64>, // 备忘录时间标记（不主动提醒，仅展示）
    pub color: NoteColor,        // 标签色：Default/Orange/Cyan/Gold（复用现有 tone token）
}

pub struct NoteBook {
    pub schema_version: u32,
    pub notes: Vec<Note>,
}
```
全部 `#[serde(default, rename_all = "camelCase")]` + 显式 `impl Default`。

### 1.2 持久化（`storage/mod.rs`，仿 `:84-90` focus）
- `load_or_create_notes()` / `save_notes()` —— 一行委托到泛型 `load_or_create::<NoteBook>("notes.json")` + `write_json`，自动获得原子写 + 损坏备份

### 1.3 AppState（`app_state.rs`，仿 focus 字段）
- 加 `pub notes: RwLock<NoteBook>` 字段 + `load()` 里加载

### 1.4 Commands（`commands/mod.rs`，仿 focus session 的写锁→save→drop→emit 模式）
```rust
create_note(kind, title, body, memo_due_at, color) -> NoteBook
update_note(id, title, body, memo_due_at, color) -> NoteBook
toggle_note_pinned(id) -> NoteBook
toggle_note_archived(id) -> NoteBook
delete_note(id) -> NoteBook   // 硬删除
get_notes() -> NoteBook        // 读
```
每个写命令：写锁 → 改 → `save_notes` → clone 出 → drop 锁 → `emit(NOTES_UPDATED, book)`

### 1.5 事件（`events.rs`）
- `pub const NOTES_UPDATED: &str = "notes:updated";`

### 1.6 注册（`lib.rs`）
- `generate_handler!` 列表加 6 个命令

type NoteKind = "note" | "memo";

### 2.2 Bridge（`tauriCommands.ts`，仿 getTodaySuggestions）

### 2.3 Store（`src/stores/notesStore.ts`，仿 suggestionsStore + 加 filter）
```ts
interface NotesStore {
  book: NoteBook | null;
  filter: NotesFilter;          // 当前筛选
  editingId: string | null;     // 当前内联展开编辑的笔记 id
  isLoading/loadError;

  loadNotes();

```
所有写操作后 store 自动刷新（命令返回最新 book）。

## 阶段 3：Markdown 渲染器（零依赖）

### 新文件 `src/services/markdown.ts`（~80 行）
- `renderMarkdown(src: string): string` —— 输入 markdown 源，输出**已转义的 HTML 字符串**
- 覆盖：`# 标题`、`- 列表`、`**粗体**`、`` `代码` ``、`[链接](url)`、空行分段
- **先转义 HTML**（`<`→`&lt;` 等）防 XSS，再解析 markdown 语法
- 前端用 `<div dangerouslySetInnerHTML>` 渲染（项目 CSP 已限 `default-src 'self'`，安全）
- 不支持嵌套/复杂语法（极简，对齐 boostnote 早期理念）

## 阶段 4：UI 页面（`src/pages/notes/NotesPage.tsx`）

### 4.1 路由接入（3 touchpoint）
- `routeTypes.ts` 加 `"notes"`
- `routes.tsx` 加 lazy 条目
- `MainWindow.tsx` routeLabels 加 `notes: { icon: "log", text: "笔记" }`（复用 log 图标）

### 4.2 页面结构（仿 HealthPage 的 3 态 + 顶部筛选）
```
cwp-page
├── page-title-row cwp-notes-title-row  (标题 + 「+新建」按钮 + 筛选 tabs)
└── cwp-notes-content (可滚动, flex column, webkit 滚动条)
    ├── 空状态: cwp-notes-empty (虚线框 + 引导文案)
    └── 笔记列表: .cwp-note-card × N
        每个 .cwp-note-card:
        ├── 折叠态: 标题 + 时间 + color 标签 + pinned 角标 + 右键菜单(置顶/归档/删除)
        └── 展开态(editingId===id): 标题input + body textarea + 保存/取消
```

### 4.3 内联编辑交互
- 点击卡片 → `setEditingId(id)` → 卡片展开成编辑区
- 标题：`<input class="cwp-note-title-input">`（复用 focus-input 风格）
- 正文：`<textarea class="cwp-note-editor">`（新类，首个 textarea）
- 保存：失焦 / Ctrl+S / 按钮 → `updateNote` → 折叠
- 取消：Esc / 按钮 → 折叠（不保存）
- 新建：标题栏「+」按钮 → `createNote` → 自动进入编辑态

### 4.4 筛选 tabs（仿 health range-tabs）
- 全部 / 笔记 / 备忘录 / 置顶 / 归档
- pinned 项永远排前；archived 默认隐藏（在「归档」tab 才显示）

### 4.5 CSS（`core-ui.css` 加 `cwp-notes-*` + `cwp-note-editor`）
- `cwp-note-card`：复用 card 配方（2px border-soft + bg-850 + 0 圆角），左边 4px color 色条（按 NoteColor）
- `cwp-note-editor`：textarea 样式（min-height 120px / resize:vertical / surface-800 bg / cyan focus / mono 字体）
- color 色条映射：default→border-soft, orange→brand-orange, cyan→tech-cyan, gold→insight-gold
- 折叠/展开用 `max-height` 过渡或条件渲染（条件渲染更简单可靠）
