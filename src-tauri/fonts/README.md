# Taskbar font

`NotoSansCJKsc-CoworkPal.otf` is a size-reduced subset of Noto Sans CJK SC
Regular 2.004 from `notofonts/noto-cjk` commit
`f8d157532fbfaeda587e826d4cd5b21a49186f7c`.

- Upstream file: `Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf`
- Upstream SHA-256: `2C76254F6FC379FDDFCE0A7E84FB5385BB135D3E399294F6EEB6680D0365B74B`
- Subset SHA-256: `7D64025473842AF6768CB49348C03DC086A704930714CFC512665D5EE9EB8D9A`
- License: SIL Open Font License 1.1; see `NotoSansCJKsc-OFL.txt`

The subset contains printable ASCII, the degree symbol, and the three Chinese
characters used by the taskbar empty state. It was generated with fonttools
4.59.1 using this Unicode set:

```text
U+0020-007E,U+00B0,U+62E9,U+672A,U+9009
```
