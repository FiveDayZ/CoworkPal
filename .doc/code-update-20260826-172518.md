## 4. New and Optimized Content

5. Windows 任务栏监控使用 DirectWrite/Direct2D 与内置字体，增加 DPI 和透明背景兼容处理。

## 5. Fixed Bugs

### 自动备份设置切换页面后丢失

- 现象：勾选自动备份或修改间隔后切换页面，设置恢复为旧值。
- 触发条件：仅改变设置页控件但未再执行手动保存。
- 根因：控件只调用本地 `setSyncConfig`，没有持久化到 Tauri 配置。
- 修复：变更时调用 `updateSyncConfig`，保存失败时回读并恢复。
- 风险：保存期间控件暂时禁用，避免并发覆盖。
- 证据：TypeScript 类型检查通过，既有页面交互截图见 `.doc/evidence-auto-backup-persistence-20260826.png`。

### 自动备份启动后长期没有上传

- 现象：设置 30 分钟后未观察到新备份，而手动上传正常。
- 触发条件：应用重启或自动备份调度重新建立。
- 根因：调度首次建立只设置 `当前时间 + 间隔`，每次重启均重新等待完整周期，且令牌变化未纳入调度变化检测。
- 修复：调度首次建立或连接配置变化时立即判定为到期，上传后再设置下一周期。
- 回归风险：配置频繁变化会触发额外一次备份，但上传锁仍避免并发写入。
- 证据：`automatic_backup_uploads_immediately_then_waits_for_the_interval` 单元测试通过；运行日志已观察到自动上传成功记录。
