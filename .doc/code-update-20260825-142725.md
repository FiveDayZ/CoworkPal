## 5. Fixed Bugs

### 设置中的硬件监控无法启用

- 现象：点击“内置硬件温度监控”开关后立即恢复为关闭。
- 触发条件：当前处于极简模式。
- 根因：`AppSettings::apply_patch` 应用开关值后，无条件执行极简模式约束；该约束再次把硬件监控改为关闭。
- 影响范围：极简模式下无法使用内置 CPU/GPU 温度传感器助手。
- 修复方法：将硬件监控改为极简模式下的显式可选项，默认进入极简模式时仍关闭；新增 schema 5 一次性迁移区分旧冲突配置和用户新选择。
- 回归风险：用户在极简模式中主动开启硬件监控后，传感器助手会增加内存占用；这是明确选择后的预期代价。
- 验证证据：模型测试确认开关值可保持为 `true`，存储测试确认 schema 5 重启后仍为 `true`，旧 schema 4 冲突配置仍会安全迁移为 `false`。
