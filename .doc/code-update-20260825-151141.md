## 5. Fixed Bugs

### 任务栏字体粗糙且不同缩放设备显示不一致

- 现象：原截图中字体偏粗、锯齿明显；代码在所有 DPI 下把字体像素高度限制为 13 至 16，并固定每列 96 像素。
- 触发条件：Windows 使用 125%、150%、200% 等非 100% 缩放时，字体不会随 DPI 正确放大，列宽和字号比例也会变化。
- 根因：硬编码 `Tahoma`、`FW_SEMIBOLD`、`NONANTIALIASED_QUALITY`，且未读取任务栏窗口 DPI。
- 影响范围：Windows 原生任务栏监控的两行三列文本。
- 修复方式：改用 Segoe UI 9pt、ClearType Natural、常规字重，并按窗口 DPI 同步缩放字体和布局。
- 回归风险：实体设备仅验证当前 200% DPI 和浅色任务栏；其他 DPI 使用单元测试验证换算，未做实体显示验证。
- 验证证据：运行窗口 DPI 为 192，原生任务栏监控区域为 392x96；截图 `.tmp/taskbar-font-after-final.png` 中 CPU、RAM、GPU、温度和内存值均清晰显示且无省略、裁切或重叠。
