## 5. Fixed Bugs

### 退出登录显示错误文本

- 现象：点击退出后，错误区显示 `[object MouseEvent]`。
- 触发条件：管理员成功登录后点击退出按钮。
- 根因：事件监听器把浏览器点击事件对象直接作为 `logout` 的提示消息参数。
- 影响范围：管理看板退出后的登录页。
- 修复方法：使用无参数回调调用 `logout()`。
- 回归风险：低。
- 验证证据：浏览器复测退出后错误区为空，管理员会话被清除并返回登录页。

### 看板自动聚焦导致误筛选

- 现象：登录后搜索框自动获得焦点，用户在其他操作中输入的文字可能被写入筛选框，列表突然变成空结果。
- 触发条件：登录完成后立即继续键盘输入。
- 根因：`showDashboard()` 强制聚焦搜索框。
- 影响范围：全用户列表显示。
- 修复方法：取消登录后的自动聚焦，页面默认焦点保持在正文。
- 回归风险：低。
- 验证证据：刷新后活动元素为 `BODY`，2 位用户保持可见。
