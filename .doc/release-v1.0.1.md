# CoworkPal v1.0.1

本版本完善了自托管数据同步、硬件监控和 Windows 桌面显示体验。

## 主要更新

- 自动备份在启用、应用启动或同步配置变化后立即上传一次，之后按设定间隔继续上传。
- 客户端支持申请用户令牌，管理员审核发放后自动保存并用于同步。
- 云端管理看板集中展示用户在线时间、工坊等级、日报、体检、成就、笔记和设备配置。
- 自托管同步支持 HTTP 与 HTTPS，Docker Compose 默认通过 `18080` 端口提供服务。
- 内置硬件传感器助手和 PawnIO 安装程序，增加安装包完整性校验、诊断日志及输出目录保护。
- 任务栏监控改用 DirectWrite 与 Direct2D 渲染，补充 DPI 感知、内置字体及透明背景合成。
- 增加生产日志轮换、Windows STA 初始化和窗口生命周期保护，提升长期运行稳定性。

## 下载

- `CoworkPal_1.0.1_x64-setup.exe`：Windows x64 NSIS 安装程序。
- `CoworkPal_1.0.1_x64-setup.exe.sha256`：安装程序 SHA-256 校验文件。

HTTP 同步内容不会加密，建议仅在可信局域网使用；通过互联网访问时仍建议配置 HTTPS 反向代理。
