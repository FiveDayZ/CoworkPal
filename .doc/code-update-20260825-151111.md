## 5. Fixed Bugs

### 用户详情缺少 CPU 和显卡配置

- 现象：点击用户只能看到应用开关和工坊数据，无法识别其 CPU、显卡等设备配置。
- 触发条件：管理员在全用户看板展开已备份用户。
- 根因：原快照只包含应用设置和持久业务数据，没有静态硬件配置；管理 API 因此无数据可展示。
- 影响范围：客户端备份格式、管理 API 和用户详情看板。
- 修复方法：新增向后兼容的静态 `deviceProfile`，管理 API生成硬件摘要并在用户详情中展示。
- 回归风险：新版备份会略微增大；旧客户端上传的备份显示“等待客户端重新上传备份”。
- 验证证据：管理 API 返回本机 AMD Ryzen 9 7940HS、NVIDIA RTX 4060、8 核 16 线程和 31.2 GB 内存；浏览器点击用户后完整显示。

### 极窄看板出现横向滚动

- 现象：约 311 px 宽的内置浏览器侧栏出现横向滚动条。
- 触发条件：窗口可用宽度小于 320 px。
- 根因：`body` 设置了 `min-width: 320px`。
- 影响范围：极窄内置浏览器和小窗口。
- 修复方法：取消强制最小宽度，继续使用既有响应式网格和文本换行。
- 回归风险：低。
- 验证证据：复测 `documentElement.scrollWidth` 与 `clientWidth` 均为 311，无横向溢出。
