## 5. Fixed Bugs

### 任务栏文字过粗、两行比例与参考效果不一致

- 现象：原字体为 Tahoma Semibold，字重明显偏粗；字体高度和行高由任务栏物理高度临时计算，在高 DPI 设备上视觉比例不稳定。
- 触发条件：启用任务栏监控，尤其是在 200% DPI 的 Windows 任务栏中显示两行数据时。
- 根因：字体名称、字重、渲染质量和行区域未采用统一的 DPI 逻辑尺寸。
- 影响范围：Windows 原生任务栏监控文字。
- 修复方法：使用 9pt Microsoft YaHei Light、常规字重、ClearType Natural，并固定 16 逻辑像素行高后按窗口 DPI 缩放。
- 回归风险：没有 Microsoft YaHei Light 的非中文 Windows 环境会由 GDI 进行字体回退，外观可能略有差异。
- 验证证据：当前设备 DPI 192，原生任务栏监控窗口 392x96；截图中三列双行文字完整、清晰、无裁切、无省略、无重叠。
