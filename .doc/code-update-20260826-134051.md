## 5. Fixed Bugs

### 局域网无法访问看板

- 现象：使用 `192.168.124.13:18080` 从其他设备访问时，Docker 端口仅绑定回环地址。
- 触发条件：从服务器之外的局域网设备访问管理看板。
- 根因：`COWORKPAL_SYNC_BIND=127.0.0.1`。
- 影响范围：局域网管理看板和健康检查。
- 修复方法：将 Env 和 Compose 默认绑定地址改为 `0.0.0.0`。
- 回归风险：管理服务现在会暴露给能访问服务器 `18080` 端口的设备，需要防火墙和强管理员令牌保护。
- 验证证据：本机重建后的端口状态为 `0.0.0.0:18080->18080/tcp`，容器健康状态为 `healthy`。
