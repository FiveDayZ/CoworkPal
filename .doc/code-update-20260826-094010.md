## 4. New and Optimized Content

1. 之前所有设备均使用 WebView2 默认 GPU 渲染路径；现在当 DXGI 主 GPU 名称匹配 Intel UHD/HD Graphics，且独立显存不超过 512 MiB 或无法报告独立显存时，使用 `--disable-gpu` 软件渲染。检测结果通过 `OnceLock` 缓存，每个进程只执行一次。
2. 新增 `COWORKPAL_DISABLE_WEBVIEW_GPU=1` 或 `true` 强制兼容开关，便于在未被自动规则覆盖的设备上诊断和绕过 WebView2 GPU 初始化问题。
3. 兼容参数应用于统一的延迟 WebView2 创建入口，主界面、CoCat、监控条和设置等窗口保持一致参数。
4. Windows 安装包由联网下载 WebView2 Bootstrapper 改为静默离线安装 WebView2 Runtime，避免目标设备安装时网络不可用或 Runtime 不完整。代价是安装包增大至约 267 MiB。
5. 未新增第三方依赖；复用了现有 DXGI GPU 查询和 Tauri WebView2 参数能力。
