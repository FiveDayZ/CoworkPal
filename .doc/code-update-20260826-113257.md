## 4. New and Optimized Content

### 4.1 预乘 Alpha 文字合成

- 之前：Direct2D 直接绑定 `WM_PAINT` 的窗口 HDC，窗口透明依赖 `LWA_COLORKEY`。灰度抗锯齿边缘会被色键截断，造成文字发硬和发虚。
- 现在：创建 32 位、从上到下的 DIBSection 内存表面，Direct2D 使用 `D2D1_ALPHA_MODE_PREMULTIPLIED` 绘制透明背景和文字，再通过 `UpdateLayeredWindow + ULW_ALPHA + AC_SRC_ALPHA` 合成到任务栏窗口。
- 原因：该路径保留字形边缘的 Alpha 覆盖率，更接近 TrafficMonitor 的 DirectWrite/Direct2D Alpha 合成方式。
- 影响范围：仅 Windows 原生任务栏监控文字。

### 4.2 字形定位

- 在 `DrawTextLayout` 中加入 `D2D1_DRAW_TEXT_OPTIONS_NO_SNAP`，并保留 `CLIP`。
- 继续使用内置固定字体、正常字重、灰度抗锯齿和 DPI 感知尺寸。

### 4.3 兼容回退

- Alpha 合成失败时，仍回退到原有 GDI + 色键路径并记录一次警告。
- 未引入 WIC、D3D10 或 DirectComposition 依赖，继续复用现有 `windows` crate 和原生 GDI/Direct2D 能力。

## 5. Fixed Bugs

### 色键透明破坏文字抗锯齿边缘

- 现象：DirectWrite 版本仍比 TrafficMonitor 模糊、边缘不自然。
- 触发条件：任务栏窗口使用 `LWA_COLORKEY` 透明，同时向窗口 HDC 绘制灰度抗锯齿文字。
- 根因：色键透明只支持像素级抠色，无法保留抗锯齿边缘的连续 Alpha 覆盖率。
- 影响范围：所有启用任务栏监控的 Windows 设备，低字号和高 DPI 下更明显。
- 修复：将主渲染路径切换为预乘 Alpha DIBSection，并使用 `UpdateLayeredWindow` 做逐像素 Alpha 合成；增加 `NO_SNAP`。
- 回归风险：部分旧系统或特殊 Explorer 环境可能不支持子窗口的 Alpha 合成，届时会自动回退 GDI。
- 验证证据：Release 程序在 Windows 11、192 DPI 下创建并显示 `CoworkPalNativeTaskbarMonitor`，窗口尺寸为 196 x 48，`UpdateLayeredWindow` 未触发错误或 GDI 回退；截图位于 `.doc/evidence-taskbar-alpha-release-20260826.png`。
