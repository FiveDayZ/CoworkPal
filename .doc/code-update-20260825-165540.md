## 4. New and Optimized Content

6. 增加可选自托管完整数据同步、定时自动备份、历史恢复和管理看板；默认仍为纯本地运行。

- 任务栏文字粗、行距大且高 DPI 不一致：改为原生 DPI 感知排版。证据：DPI 缩放单元测试和此前任务栏窗口实机证据通过。
