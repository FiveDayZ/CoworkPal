## 4. New and Optimized Content

### 4.1 WebView 按需启动

- 之前行为：即使关闭 CoCat 和悬浮监控条、只显示原生任务栏监控，Tauri 配置仍会在启动时创建 `pet` WebView；其 WebView2 进程树继续驻留。
- 新行为：Tauri 启动窗口列表为空。`main`、`pet`、`monitor-bar` 和 `pet-panel` 仍通过已有 `ensure_webview_window` 在用户实际打开时创建。
- 原因：WebView2 是极简常驻路径的主要内存来源，原生任务栏监控不依赖 WebView。
- 影响范围：关闭所有 WebView 界面时的启动和常驻内存；用户打开界面后仍会按需产生 WebView2 进程。

### 4.2 成就幂等键有界保留

- 之前行为：事件仅保留最近 2000 条，但 `idempotencyKeys` 永不清理。本机实测已累积 470325 条，`achievements.json` 达 20835877 字节，Rust `BTreeSet` 也会常驻加载全部键。
- 新行为：事件超出 2000 条时同步删除被裁剪事件的幂等键；启动时将旧幂等键集合压缩为当前保留事件对应的键。
- 原因：修复磁盘文件和内存随运行时间持续增长的问题。
- 影响范围：保留 counters、daily rollups、distinct values、unlocks、notifications、notification queue 和最近 2000 条 events；过期事件对应的旧幂等键不再永久保留，因此超过保留窗口的极旧重复事件可再次被接受。

### 4.3 温度助手无控制台宿主

- 之前行为：内置 .NET 温度助手以控制台程序启动，会额外产生约 10 MiB Working Set 的 `conhost.exe`。
- 新行为：助手输出类型为 `WinExe`，实测助手运行时 `ConhostChildren=0`。
- 原因：减少常驻进程和无用途的控制台内存。
- 影响范围：仅构建和进程形态，不改变 JSON 数据协议。

### 4.4 依赖说明

本次内存优化未新增依赖、未更改 lockfile。内置助手仍使用当前工作树已有的 `LibreHardwareMonitorLib 0.9.6` 包引用；本次仅调整其输出类型。

## 5. Fixed Bugs

### 5.1 极简界面关闭后 WebView2 仍常驻

- 现象：CoCat 和悬浮监控条关闭后，CoworkPal 进程树仍约 700.61 MiB Working Set / 408.13 MiB Private Bytes。
- 触发条件：启动应用，即使只启用原生任务栏数据显示。
- 根因：`tauri.conf.json` 固定预创建 `pet` WebView，关闭窗口不能释放整个 WebView2 环境。
- 修复：不预创建任何 WebView 窗口，沿用现有按需窗口创建逻辑。
- 回归风险：某个调用方若错误依赖 `pet` 在 setup 前已存在，可能出现窗口时序问题；现有全量 Rust 测试和极简运行路径未发现该问题。
- 验证：最终生产程序极简启动时仅 1 个 `cowork-pal` 进程，`WebViewCount=0`，原生任务栏窗口存在；发送任务栏右键消息后按需出现 6 个 WebView2 进程。

### 5.2 成就幂等键无限增长

- 现象：本机 `events=2000`，但 `idempotencyKeys=470325`，文件约 20.84 MB。
- 触发条件：长期产生硬件、工作日志和交互成就事件。
- 根因：`trim_events` 只删除事件，不删除对应幂等键。
- 修复：裁剪同步删除键，并在启动时压缩旧数据。
- 回归风险：超过最近 2000 个事件窗口的重复请求不再被永久去重。
- 验证：新增 2 个回归测试通过；实际启动后文件降至约 1.22 MB，`events=2000`、`idempotencyKeys=2000`，并保留 109 个 counters、7 组 distinct values、19 个 daily rollups、58 个 unlocks 和 1 条 notification。

### 5.3 温度助手产生额外 conhost

- 现象：旧助手进程树包含约 10.06 MiB Working Set 的 `conhost.exe`。
- 触发条件：内置温度助手常驻运行。
- 根因：项目输出类型为控制台 `Exe`。
- 修复：改为 `WinExe`。
- 回归风险：助手异常不再显示控制台文本；错误仍写入既有 `.error.log`。
- 验证：最终助手运行 5 秒，Working Set 93.57 MiB、Private 47.53 MiB、`ConhostChildren=0`，GPU 温度 JSON 持续生成。
