## 4. New and Optimized Content

1. 总览指标同步
   - 之前：顶部仅显示用户、备份、在线时间和笔记。
   - 现在：增加“日报 / 体检”和“已解锁成就”，直接汇总全部已备份用户的数据。
   - 日报和体检均由工作日志按天生成，因此两项使用相同的工作日志天数并以 `日报 / 体检` 双值形式显示。

2. 用户详情重组
   - 之前：工坊和数据数量混在同一信息组中，日报和体检没有独立名称。
   - 现在：详情依次显示“备份信息、工坊状态、云端数据、应用设置、硬件配置、模块等级”。
   - “云端数据”独立展示笔记、专注记录、日报、体检和成就数量，并用绿色数字增强扫描效率。

3. 响应式布局
   - 大屏使用六列总览和十二列详情网格；核心信息为三列，应用设置与硬件配置为两列。
   - 中等宽度降为三列总览和两列详情。
   - 手机宽度降为两列总览和单列详情，用户概要自动隐藏次要指标。

4. 兼容性
   - 服务端 `summarizeBackup` 已提供 `workLogDays` 和 `achievements`，本次未修改 API、快照协议或持久化结构。
   - 旧客户端快照仍按既有规则显示；没有新增数据迁移要求。
