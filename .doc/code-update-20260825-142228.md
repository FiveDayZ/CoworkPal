## 5. Fixed Bugs

- 现象：容器创建成功但启动失败，Docker 报告无法绑定 `127.0.0.1:8080`。
- 触发条件：Windows 将 8080 纳入 TCP 排除端口区间。
- 根因：Compose 固定发布主机端口 8080。
- 修复：增加 `COWORKPAL_SYNC_PORT` 主机端口变量，本机验证使用 18080。
- 回归风险：低；未配置变量时仍使用原来的 8080。
- 验证证据：容器在 `127.0.0.1:18080` 健康运行，API 和数据卷测试通过。
