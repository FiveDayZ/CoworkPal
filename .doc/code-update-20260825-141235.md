## 4. New and Optimized Content

1. 新增无第三方 npm 依赖的自托管同步服务。此前没有服务端备份；现在可按用户令牌保存完整快照，最新快照原子替换，并默认保留最近 30 个版本。
2. 新增手动完整上传。快照包含设置、工坊、窗口布局、工况日志、专注记录、成就、笔记；实时硬件指标、进程列表和同步令牌不包含在快照中。
3. 新增手动云端恢复。恢复前校验快照版本、工坊数值、窗口坐标和笔记 ID；恢复失败时尝试回滚本地数据，进程中断时由恢复日志在下次启动继续完成。
4. 新增安全边界。远程地址必须使用 HTTPS，仅 localhost/127.0.0.1/::1 允许 HTTP；访问令牌至少 32 个字符；服务端不记录令牌或快照正文。
5. 没有新增或升级依赖。服务端使用 Node.js 标准库；桌面端复用已有 `reqwest`、`serde` 和 Tauri 能力，锁文件未变化。
