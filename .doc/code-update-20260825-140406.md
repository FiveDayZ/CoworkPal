## 5. Fixed Bugs

### 极简模式仍启动高内存子进程

- 现象：`minimalModeEnabled=true` 时，设置中仍可能出现 `integratedHardwareMonitorEnabled=true`，同时驻留 CoworkPal WebView2 和 `coworkpal-hardware-monitor.exe`。
- 触发条件：旧版极简设置、后续设置补丁覆盖，或主窗口关闭时仅执行隐藏。
- 根因：极简模式缺少模型层不可变约束，窗口关闭路径没有销毁 WebView。
- 影响范围：极简模式常驻内存。
- 修复方法：统一设置约束、启动持久化修正、关闭窗口时销毁 WebView。
- 回归风险：重新退出极简模式时依赖原有恢复快照；相关切换和缺失快照均有单元测试。
- 验证证据：最新版在现有极简配置下启动 20 秒及 60 秒后均没有 CoworkPal WebView2 子进程，也没有硬件传感器助手；设置已自动修正为 `integratedHardwareMonitorEnabled=false`。
