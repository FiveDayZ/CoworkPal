## 5. Fixed Bugs

### 远程 HTTP 同步地址被客户端拒绝

- 现象：填写 `http://192.168.124.13:18080` 时，客户端返回“远程同步服务器必须使用 HTTPS”。
- 触发条件：服务器地址为远程主机的 HTTP URL。
- 根因：`api_endpoint` 仅允许 HTTPS，并只对 localhost / 回环地址放行 HTTP。
- 影响范围：HTTP 环境下的保存配置、申请令牌、手动上传、恢复和自动备份。
- 修复方法：协议白名单调整为 HTTP 与 HTTPS，删除只针对本机 HTTP 的判断。
- 回归风险：HTTP 会明文传输访问令牌和备份内容。
- 验证证据：Rust 测试确认远程 HTTP 与 HTTPS 均通过、FTP 被拒绝；浏览器设置页成功保存 HTTP 地址并显示“同步配置已保存”。
