## 4. New and Optimized Content

1. 新增 PawnIO 2.2.0 前置条件检测。
   - 旧行为：CoworkPal 仅打包 `LibreHardwareMonitorLib 0.9.6`，未提供其读取 Intel MSR 温度所需的 PawnIO 内核驱动；未安装驱动的设备可以枚举传感器名称，但数值均为 `null`。
   - 新行为：辅助进程从注册表读取 PawnIO 版本；2.2.0 以下或未安装时运行随包安装程序。
   - 原因：N305 日志已经排除 IPC 路径问题，并确认传感器枚举成功但底层值全部为空。
   - 影响范围：用户主动开启“内置硬件监控”时的 CPU 温度读取。

2. 安装程序执行前进行 SHA-256 固定值校验。
   - 固定哈希：`1F519A22E47187F70A1379A48CA604981C4FCF694F4E65B734AAA74A9FBA3032`。
   - 校验失败时不执行安装程序，辅助进程以退出码 4 结束并写入诊断。
   - 安装程序返回 3010 时以退出码 5 提示必须重启 Windows。

3. 增加 `--validate-pawnio-installer` 内部自检模式，供构建和发布验证使用。

4. CPU 温度为空时的诊断现在包含 `pawnio='版本号'`，便于区分未安装驱动、驱动已安装但硬件仍不兼容两种情况。

5. 设置页说明改为“首次开启会请求管理员权限，并自动安装随应用提供的硬件访问驱动”，避免后台安装行为不透明。

## 5. Fixed Bugs

### 未安装 PawnIO 的 Intel 设备无法读取 CPU 温度

- 现象：内置硬件监控已启用，CPU 温度仍显示为空；日志中 Intel Core i3-N305 的 `Core Max`、`Core Average`、`E-Core #1` 至 `#8` 和 `CPU Package` 全部为 `null`。
- 触发条件：设备未安装 LibreHardwareMonitor 0.9.6 进行 Intel MSR 硬件访问所需的 PawnIO 驱动。
- 根因：CoworkPal 之前只集成 .NET 传感器库，没有像 LibreHardwareMonitor 官方桌面程序一样提供 PawnIO 安装程序。
- 影响范围：未预装 PawnIO 的 Intel CPU 设备；已预装兼容驱动的设备不受此根因影响。
- 修复方法：随应用分发官方 PawnIO 2.2.0 安装程序，首次启用时进行版本检测、哈希校验和静默安装。
- 回归风险：安装内核驱动需要管理员权限和企业安全策略许可；部分系统可能要求重启；N305 是否在安装驱动后返回有效温度仍需目标设备验证。
- 验证证据：本机已安装 PawnIO 2.2.0，辅助进程能够识别版本并通过安装程序完整性自检；完整 Tauri 打包将 PawnIO sidecar 放入 release 目录并成功生成 NSIS 包。
- 未完成证据：当前环境未卸载现有内核驱动，因此没有执行缺少 PawnIO 时的自动安装分支；用户 N305 设备尚未安装新包复测。

## 8. Supplementary Remarks

- PawnIO 版本：2.2.0。
- 用途：为 LibreHardwareMonitor 的 Intel CPU MSR 温度访问提供 Windows 内核级硬件访问。
- 选择原因：与当前 `LibreHardwareMonitorLib 0.9.6` 的官方桌面程序方案一致；自行实现或引入其他内核驱动会增加签名、安全和维护风险。
- 替代方案：要求用户单独安装 PawnIO（体验差且容易遗漏）；更换完整硬件监控栈（改动和兼容风险更大）；本次均未采用。
- 官方来源：`https://github.com/namazso/PawnIO.Setup/releases/download/2.2.0/PawnIO_setup.exe`。
- 锁文件：没有新增 NuGet、Cargo 或 npm 包，也没有因本次 PawnIO 集成修改依赖锁文件。
- 日志路径：`%APPDATA%\CoworkPal\logs\coworkpal.log`。
- 目标设备复测时重点搜索：`pawnio=`、`CPU temperature unavailable`、`exit_code=4`、`exit_code=5`。
